PROYECTO ESCOLAR · ARDUINO UNO

Monitoreo ambiental inteligente

AIRSAFE SCHOOL es un prototipo diseñado para vigilar la calidad del aire en espacios escolares mediante sensores de gases, indicadores luminosos y una alarma sonora.

Conocer el proyecto ↓

¿Qué es AIRSAFE SCHOOL?

Un sistema educativo de monitoreo y alerta ambiental.

🌬️

Monitoreo

Los sensores realizan lecturas del ambiente y entregan valores al Arduino para su procesamiento.

🚨

Alerta

Cuando una lectura supera el umbral configurado, se activa una señal visual y sonora.

💻

Programación

El Arduino Uno procesa las señales y controla los indicadores del prototipo.

Lógica del programa

Explicacion de la lógica usada en el prototipo.

// Librería para comunicación serial con el ESP8266
#include 

// Crea una comunicación serial virtual
// Pin 10 = RX, Pin 11 = TX
SoftwareSerial esp8266(10, 11);

// Pines de los sensores
const int mq2Pin = A0;      // Sensor MQ-2 conectado al pin analógico A0
const int mq135Pin = A1;    // Sensor MQ-135 conectado al pin analógico A1

// Pines de los LEDs
const int ledVerde = 2;     // LED verde = estado normal
const int ledRojo = 3;      // LED rojo = alerta
const int ledAzul = 4;      // LED azul = sistema activo

// Pin del buzzer
const int buzzer = 5;

// Valores límite para activar la alerta
const int umbralMQ2 = 450;
const int umbralMQ135 = 400;


// Función que se ejecuta una sola vez al iniciar
void setup() {

  // Inicia comunicación con el monitor serial
  Serial.begin(9600);

  // Inicia comunicación con el ESP8266
  esp8266.begin(9600);

  // Configura los LEDs como salidas
  pinMode(ledVerde, OUTPUT);
  pinMode(ledRojo, OUTPUT);
  pinMode(ledAzul, OUTPUT);

  // Configura el buzzer como salida
  pinMode(buzzer, OUTPUT);

  // Enciende el LED azul para indicar que el sistema está funcionando
  digitalWrite(ledAzul, HIGH);

  // Mensaje de inicio en el monitor serial
  Serial.println("AIRSAFE SCHOOL - Arduino Uno");
}


// Función principal que se repite continuamente
void loop() {

  // Lee el valor analógico del sensor MQ-2
  int valorMQ2 = analogRead(mq2Pin);

  // Lee el valor analógico del sensor MQ-135
  int valorMQ135 = analogRead(mq135Pin);

  // Muestra el valor del MQ-2 en el monitor serial
  Serial.print("MQ2: ");
  Serial.print(valorMQ2);

  // Muestra el valor del MQ-135
  Serial.print(" | MQ135: ");
  Serial.println(valorMQ135);

  // Comprueba si alguno de los sensores supera el umbral
  if (valorMQ2 > umbralMQ2 || valorMQ135 > umbralMQ135) {

    // Apaga el LED verde
    digitalWrite(ledVerde, LOW);

    // Enciende el LED rojo
    digitalWrite(ledRojo, HIGH);

    // Activa el buzzer a 1000 Hz
    tone(buzzer, 1000);

    // Envía una alerta por WiFi
    enviarAlerta();

  } else {

    // Enciende el LED verde indicando estado normal
    digitalWrite(ledVerde, HIGH);

    // Apaga el LED rojo
    digitalWrite(ledRojo, LOW);

    // Apaga el buzzer
    noTone(buzzer);
  }

  // Espera 2 segundos antes de volver a leer
  delay(2000);
}


// Función para enviar una alerta al ESP8266
void enviarAlerta() {

  // Envía un mensaje al módulo WiFi
  esp8266.println("ALERTA: Calidad del aire fuera de rango");

}

Importante

Este prototipo es un monitor ambiental. Los sensores MQ no identifican de forma fiable una sustancia psicoactiva específica ni pueden determinar por sí solos si una persona consumió una sustancia. Las alertas indican que una lectura del ambiente está fuera del rango configurado y requieren revisión responsable.
